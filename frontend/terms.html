제1조 (목적)

이 약관은 Kiwi Karlsen(이하 "서비스")이 제공하는 온라인 체스 서비스의 이용 조건과 절차, 이용자와 운영자의 권리·의무를 규정합니다.

제2조 (서비스 내용)

  • 온라인 체스 대국(사용자 간 / 봇 대국)
  • 체스 퍼즐, 퍼즐 러시, 퍼즐 전투, 시각 훈련
  • 오프닝 탐색기 및 학습, 게임 분석 및 리뷰, 통찰(통계)
  • 친구, 클럽, 채팅 등 커뮤니티 기능

서비스는 개인이 학습 목적으로 운영하며, 무료로 제공됩니다. 광고나 유료 결제는 없습니다.

제3조 (계정)

  • 계정 하나당 한 사람이 사용해야 합니다.
  • 비밀번호 관리 책임은 이용자에게 있습니다. 2단계 인증(2FA) 사용을 권장합니다.
  • 사용자명은 90일마다 한 번 변경할 수 있습니다.
  • 언제든지 회원 탈퇴가 가능하며, 개인정보는 즉시 삭제됩니다.

제4조 (금지 행위)

  • 부정행위(치팅): 대국 중 체스 엔진·프로그램의 도움을 받는 행위
  • 자동화 도구(봇)를 이용한 대량 요청, 계정 자동 생성
  • 다른 이용자에 대한 욕설, 괴롭힘, 차별적 표현
  • 서비스의 취약점을 악용하거나 무단으로 접근을 시도하는 행위
  • 타인의 계정을 도용하거나 권한 없이 접근하는 행위

위반 시 경고 없이 계정이 정지될 수 있습니다. 자동 탐지 시스템이 비정상적인 행동 패턴(비인간적인 요청 속도 등)을 모니터링합니다.

제5조 (콘텐츠)

이용자가 작성한 글·채팅의 책임은 작성자에게 있습니다. 운영자는 약관을 위반하는 콘텐츠를 사전 통보 없이 삭제할 수 있습니다.

제6조 (면책)

서비스는 있는 그대로 제공되며, 무료 호스팅 환경 특성상 데이터 손실이나 서비스 중단이 발생할 수 있습니다. 운영자는 이에 대해 법적 책임을 지지 않습니다. 중요한 기보는 직접 내려받아 보관하시길 권장합니다(프로필 → PGN 내려받기).

제7조 (약관 변경)

약관이 변경되면 이 페이지에 공지합니다. 변경 후에도 서비스를 계속 이용하면 변경된 약관에 동의한 것으로 봅니다.

이메일 주소를 수집하지 않습니다. 광고 추적기, 분석 스크립트(Google Analytics 등)를 일절 사용하지 않습니다. 제3자에게 개인정보를 제공하거나 판매하지 않습니다.

2. IP 주소 처리

보안 로그에는 IP 주소의 원문이 저장되지 않습니다. 서버 비밀키로 해시한 값(32자)만 기록하므로, 데이터베이스가 유출되어도 IP를 역추적할 수 없습니다.

3. 쿠키

추적 쿠키를 사용하지 않습니다. 로그인 상태는 브라우저의 로컬 저장소(localStorage)에 보관되며, 로그아웃하면 삭제됩니다.

4. 보관 기간

  • 계정 정보: 탈퇴 시 즉시 삭제
  • 보안 로그: 최근 기록만 보관 (해시된 IP)
  • 대국 기록: 상대방의 전적이기도 하므로 유지되나, 탈퇴 시 내 이름은 "탈퇴한 사용자"로 익명화됩니다.

5. 이용자의 권리

  • 열람·이동권: 프로필 → 계정 보안 → "내 데이터 내보내기"로 모든 개인정보를 JSON으로 받을 수 있습니다.
  • 정정권: 프로필에서 언제든 수정 가능합니다.
  • 삭제권: 프로필 → 계정 보안 → "회원 탈퇴"로 즉시 삭제할 수 있습니다.

🛡️ 이 사이트의 보안 수준

어떤 보안 조치를 적용했는지 투명하게 공개합니다.

비밀번호

  • scrypt (N=2¹⁵, r=8, p=1) — 메모리 하드 알고리즘으로 GPU/ASIC 대량 크래킹에 강함
  • 페퍼(pepper) 적용 — 데이터베이스만 유출돼도 서버 비밀키 없이는 크래킹이 사실상 불가능
  • 사용자마다 다른 무작위 솔트(salt)
  • 상수 시간 비교로 타이밍 공격 방어
  • 정책: 8자 이상, 문자 종류 2가지 이상, 연속·반복 패턴 및 사용자명 포함 차단, 흔한 비밀번호 차단

인증 · 세션

  • 2단계 인증(2FA) — TOTP 표준(RFC 6238). 인증 앱 + 1회용 백업 코드 10개
  • HMAC-SHA256 서명 토큰 (유효기간 7일)
  • 토큰 즉시 폐기 — 비밀번호 변경이나 "전체 로그아웃" 시 모든 기기의 세션이 무효화
  • 무차별 대입 방어 — 실패 누적 시 지수적 잠금(30초 → 최대 30분)
  • 로그인 실패 시 사용자 존재 여부를 노출하지 않음

웹 공격 방어

  • XSS — 저장 시점 정화 + 출력 시점 이스케이프(이중 방어), CSP로 인라인 스크립트 차단
  • SQL Injection — ORM 파라미터 바인딩만 사용(원시 SQL 없음), LIKE 와일드카드 이스케이프
  • CSRF — 쿠키가 아닌 Authorization 헤더 방식이라 구조적으로 불가능
  • 클릭재킹 — X-Frame-Options: DENY, CSP frame-ancestors 'none'
  • WebSocket 하이재킹(CSWSH) — Origin 헤더 검증
  • 중간자 공격 — HSTS(2년, preload)로 HTTPS 강제
  • 모든 API 입력을 엄격한 스키마로 검증(타입·길이·범위)

남용 방지

  • 경로별 레이트 리밋(로그인·DM·엔진 등 등급별)
  • IP당 하루 가입 상한 + 봇 허니팟
  • 자동화 탐지 — 요청 간격 패턴 분석으로 봇 의심 계정 식별

개인정보

  • 이메일 미수집, 추적기·광고 없음
  • IP는 해시로만 저장 — 유출돼도 역추적 불가
  • 모든 관리자 행위를 감사 로그에 기록
  • 데이터 내보내기 및 즉시 탈퇴 지원
